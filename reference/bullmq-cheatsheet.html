BullMQ Cheat Sheet & Reference

A quick-reference guide for adding, configuring, and processing background tasks using BullMQ in NestJS.

1. Adding Jobs (Producers)

Basic On-Demand Job

await queue.add('job-name', { foo: 'bar' });

Job with Retries & Exponential Backoff

await queue.add(
  'job-name',
  { foo: 'bar' },
  {
    attempts: 5,
    backoff: {
      type: 'exponential',
      delay: 2000 // starts at 2s, then 4s, 8s, etc.
    }
  }
);

Repeatable Job (Cron/Scheduled)

// Runs every 15 minutes
await queue.add(
  'clean-up-job',
  {},
  {
    repeat: {
      every: 15 * 60 * 1000 // 15 minutes in ms
    }
  }
);

2. Processing Jobs (Workers)

Standard Worker Host in NestJS

import { Processor, WorkerHost } from '@nestjs/bullmq';
import { Job } from 'bullmq';

@Processor('queue-name')
export class CustomProcessor extends WorkerHost {
  async process(job: Job<any>): Promise<any> {
    switch (job.name) {
      case 'job-name':
        // execute task logic using job.data
        return { result: 'success' };
      default:
        throw new Error('Unknown job name');
    }
  }
}

3. Job Lifecycles & States

Job State Description
Waiting The job is in the queue, waiting to be picked up by a free worker.
Active The job is currently being processed by a worker.
Delayed The job has a delay or backoff timer active and is waiting to transition to 'waiting'.
Completed The job was executed successfully and resolved.
Failed The job threw an error and has completed all retry attempts.
