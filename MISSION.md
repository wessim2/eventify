# Mission: Master Core SaaS Architectural Blocks (Webpack, Swagger, BullMQ)

## Why
The user is building a multi-tenant 'Tech-Event' Operating System SaaS. They want to master the key backend architectural blocks (compilation bundling, API documentation, and asynchronous job processing) to design a decoupled, resilient, and performant backend system.

## Success looks like
- Configure custom Webpack rules to resolve monorepo module compilation mismatches.
- Generate clean Swagger OpenAPI documentation without cluttering codebase DTOs.
- Explain the role of message queues, job processors, and producers in BullMQ.
- Build resilient asynchronous tasks with retries, backoff strategies, and repeatable jobs in BullMQ.

## Constraints
- Visual explanations, conceptual mappings, and code examples from the current workspace.
- Short, incremental lessons that respect working memory limits.

## Out of scope
- Advanced Redis clustering setup or deep Redis memory optimization configs.
- Frontend state integration for queues.
