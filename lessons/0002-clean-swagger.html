Lesson 2: Clean Swagger Documentation in NestJS

In this lesson, we will explore how to document Swagger endpoints in NestJS without cluttering your DTOs and Controllers with endless decorators.

1. The Problem: Decorator Bloat

Normally, to document a DTO, you have to decorate every single field with @ApiProperty():

// ❌ Cluttered, boilerplate-heavy DTO
export class CreateEventDto {
  @ApiProperty({ description: 'The title of the event', example: 'Keynote' })
  @IsString()
  title: string;

  @ApiProperty({ description: 'Start date of the event', example: '2026-10-15T09:00:00Z' })
  @IsDateString()
  startDate: string;
}

When you have dozens of DTOs, this metadata completely overwhelms your business logic.

2. The Best Practice: The NestJS Swagger CLI Plugin

NestJS provides a compiler plugin that automatically introspects your TypeScript code at build time. It analyzes the type definitions and validation decorators (like @IsString(), @IsOptional()) and automatically injects the corresponding Swagger metadata behind the scenes.

With the plugin enabled, your DTO looks completely clean:

//  Clean, idiomatic DTO
export class CreateEventDto {
  @IsString()
  title: string;

  @IsDateString()
  startDate: string;
}

The compiler automatically infers that title is a required string and startDate is a required date-string, mapping them directly to OpenAPI schema properties!

3. How to Enable the CLI Plugin

To enable the plugin, add the plugins block to compilerOptions in your nest-cli.json configuration file:

{
  "collection": "@nestjs/schematics",
  "sourceRoot": "src",
  "compilerOptions": {
    "deleteOutDir": true,
    "webpack": true,
    "webpackConfigPath": "webpack.config.js",
    "plugins": ["@nestjs/swagger"]
  }
}

4. Keep Controllers Clean

To keep controllers clean, only use high-level decorators at the class or handler levels. Never duplicate request payload metadata that is already in your DTOs:

//  Clean Controller Documentation
@ApiTags('Events')
@ApiBearerAuth()
@Controller('events')
@UseGuards(JwtAuthGuard, TenantGuard)
export class EventController {
  
  @Post()
  @ApiOperation({ summary: 'Create a new event' })
  @ApiHeader({ name: 'X-Organization-Id', description: 'Active Tenant ID', required: true })
  @ApiResponse({ status: 201, description: 'Event successfully created' })
  create(@Body() dto: CreateEventDto) {
    // ...
  }
}
