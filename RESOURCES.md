# Webpack & SaaS Payment Resources

## Knowledge

- [Official Webpack Documentation](https://webpack.js.org/concepts/)
  Official concepts page explaining Entry, Output, Loaders, Plugins, Mode, and Browser Compatibility.
- [NestJS Webpack Compiler Documentation](https://docs.nestjs.com/recipes/hot-reload)
  Documentation on NestJS's custom Webpack setup and CLI configurations.
- [webpack-node-externals Package Reference](https://www.npmjs.com/package/webpack-node-externals)
  Explains how node externals are used in server-side bundling to exclude node_modules.
- [Stripe Connect Documentation](https://stripe.com/docs/connect)
  Official guide for platform payment routing, Express onboarding, and application fee splits.
- [Stripe Elements Integration Guide](https://stripe.com/docs/payments/elements)
  Custom checkout UI elements for securely capturing card details.
- [Resend Node.js SDK Documentation](https://resend.com/docs/sdks/node)
  Official Node.js SDK reference for sending transactional HTML emails.

## Wisdom (Communities)

- [Stack Overflow: Webpack Tag](https://stackoverflow.com/questions/tagged/webpack)
  A massive community of active frontend and backend engineers diagnosing build issues.
- [r/stripe Subreddit](https://www.reddit.com/r/stripe/)
  A community of developers building Stripe payment integrations and SaaS marketplaces.
- [Resend Discord Community](https://resend.com/discord)
  Developer community for transactional email deliverability and email engineering.
